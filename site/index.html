Welcome

OpenChessCoach

A chess coach that runs on your own desktop or laptop. The Engine (Stockfish) judges every move, and Claude, the Coach, explains why in plain language.

Set up takes about ten minutes. After that it's one command each time you want to play, on your desktop or on your phone.

Before you start

What you need

  • ✓A Windows, Mac or Linux desktop or laptop. Windows 10 or later, macOS 13 or later, or a recent Ubuntu, Debian or Fedora. The app runs there; your phone connects to it.
  • ✓A paid Claude plan (Pro or Max). The Coach runs on your own Claude subscription through Claude Code. The free Claude plan doesn't include Claude Code. Sign up at claude.ai.
  • ✓A terminal, used three times. You'll paste a few commands. Each step below says exactly what to paste.
Install

Set it up

  1. Open PowerShell

    Press Start, type PowerShell and open Windows PowerShell. You don't need to run it as administrator. Paste with Ctrl+V or a right-click, then press Enter.

  2. Install Node.js

    Node.js runs the app. Install the LTS version:

    winget install OpenJS.NodeJS.LTS

    Or download the LTS installer from nodejs.org and click through it.

    Close PowerShell and open a new one, so it finds Node.js. Then check it worked: node --version should print v22.18 or later.

  3. Install Claude Code and log in

    irm https://claude.ai/install.ps1 | iex

    Open a new PowerShell window again, then run claude. It opens your browser: sign in with your Claude account. When Claude Code says you're logged in, type /exit.

  4. Start OpenChessCoach

    npx.cmd openchesscoach@latest

    The first time, npm asks Ok to proceed? (y): press Y and Enter. Your browser opens the app, already paired.

    Windows Firewall may ask whether Node.js can use the network. Tick Private networks and click Allow, so your phone can connect.

  1. Open Terminal

    Press ⌘+Space, type Terminal and press Enter. Paste with ⌘+V, then press Enter.

  2. Install Node.js

    Node.js runs the app. Download the LTS macOS Installer (.pkg) from nodejs.org and click through it.

    If you use Homebrew, this does the same:

    brew install node

    Open a new Terminal window, then check it worked: node --version should print v22.18 or later.

  3. Install Claude Code and log in

    curl -fsSL https://claude.ai/install.sh | bash

    Open a new Terminal window, then run claude. It opens your browser: sign in with your Claude account. When Claude Code says you're logged in, type /exit.

    If the new terminal says claude isn't found, run the PATH command the installer printed at the end, then open another new terminal.

  4. Start OpenChessCoach

    npx openchesscoach@latest

    The first time, npm asks Ok to proceed? (y): press Y and Enter. Your browser opens the app, already paired.

    macOS may ask whether Node.js can accept incoming network connections. Click Allow, so your phone can connect.

  1. Open a terminal

    On Ubuntu and most desktops, press Ctrl+Alt+T, or find Terminal in your apps. Paste with Ctrl+Shift+V, then press Enter.

  2. Install Node.js

    Your distribution's own Node.js is usually too old, so install it with nvm, the Node.js version manager:

    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.8/install.sh | bash

    Open a new terminal, then install the LTS version:

    nvm install --lts

    Check it worked: node --version should print v22.18 or later.

  3. Install Claude Code and log in

    curl -fsSL https://claude.ai/install.sh | bash

    Open a new terminal, then run claude. It opens your browser, or prints a link to open: sign in with your Claude account. When Claude Code says you're logged in, type /exit.

    If the new terminal says claude isn't found, run the PATH command the installer printed at the end, then open another new terminal.

  4. Start OpenChessCoach

    npx openchesscoach@latest

    The first time, npm asks Ok to proceed? (y): press Y and Enter. Your browser opens the app, already paired. If it doesn't, open the address ending in #pair=… that the terminal prints under the QR code.

    A firewall such as ufw may block your phone. Allow port 8737 on your home network: sudo ufw allow 8737/tcp.

Every time after

Start, stop, update

StartOpen a terminal and run the same command as step 4. Keep that window open while you play: closing it stops the app.

StopPress Ctrl+C in that terminal.

UpdateNothing to do. @latest fetches the newest version each time you start it.

On your phoneThe first thing the app shows on your desktop is a QR code, and the terminal prints the same one. Scan it with your phone's camera while it's on the same Wi-Fi, and the app opens already paired. That Wi-Fi address starts with http://, so the phone needs the desktop running each time it opens the app. To play away from home, tick away-from-home access in Settings and scan the new QR code. Its https:// address is the one to add to your home screen: from there the board, the Engine, Lessons and Puzzles keep working with the desktop off. The address changes each time you start the app on the desktop, so scan again then.

Your first session

How to use it

On the first start the app asks your level and what you want to learn. Then pick anything from the main menu.

♘Lessons

Learn an opening, a Theme such as forks and pins, or a basic endgame. You choose moves, and the Coach explains the consequences of each choice.

♖Puzzles

Positions from real games where you find the strongest move. Do them after a Lesson to practise what it taught.

♔Engine Games

Play the Engine at your strength. Turn on Live Coaching for comments as you play, and ask for a Hint when you're stuck.

♕Reviews

Bring in your games from Lichess or chess.com by username, or paste a PGN. The Coach walks you through the key moments.

?Ask why

On any move, ask the Coach why it's good or bad. The Engine supplies the facts and the Coach puts them in plain words.

✓Move Grades

Every move gets a grade from Best to Blunder, based on how much it gives away compared with the best move.

♗At a glance

A bar beside the board shows each side's Winning Chances, and a graph under a Review shows where the game turned. Move Grade symbols such as ?? sit on the board, arrows show the move played and the Engine's best, and Threat shows what your opponent wants next.

If something goes wrong

Fixes for common messages

npx or node is not recognized, or command not found

Node.js isn't installed, or the terminal was opened before you installed it. Do step 2, then open a new terminal window and try again.

OpenChessCoach needs Node.js 22.18 or later

Your Node.js is too old. Install the LTS version as in step 2, open a new terminal and run the start command again.

Claude Code is not installed

Do step 3, then open a new terminal. If claude --version works in the new terminal, start OpenChessCoach from that same window.

Claude Code is installed but not logged in

Run claude, type /login and sign in. A free Claude plan can't log in to Claude Code; you need Pro or Max.

Port 8737 is already in use

OpenChessCoach is probably already running in another terminal window: use that one. Otherwise start it on another port, for example npx openchesscoach@latest --port 8738.

Windows: running scripts is disabled on this system

PowerShell blocked npx. Type npx.cmd instead of npx, exactly as in step 4.

My phone can't connect

Check the phone is on the same Wi-Fi as the desktop, and that you allowed the firewall prompt (see step 4). On guest or office Wi-Fi, devices often can't see each other: use away-from-home access in Settings instead.

The Coach says your Claude usage limit has been reached

The Coach shares your Claude plan's usage limits. The app shows when they reset. The board, the Engine, Puzzles and Engine Games keep working meanwhile.

Still stuck, or found a bug? Send a screenshot of the terminal to the person who shared this page or, if the project is public on GitHub, open an issue there with it. The terminal's first line, OpenChessCoach version is running, says which version you have.

Good to know

Your data and your Claude plan

Everything stays on your desktop.Your games and Player Profile live in one file in your data folder. There are no accounts and no server. On Windows it's %APPDATA%\ai-chess-coach, on macOS ~/Library/Application Support/ai-chess-coach, on Linux ~/.local/share/ai-chess-coach. Delete that folder to start over.

The Coach uses your Claude plan.Each Coach reply counts towards your Claude usage, like a message in Claude. The app never sees your password; it goes through Claude Code's login.

Only your devices get in.A device needs the pairing code from your desktop's QR code, so nobody else on your Wi-Fi can use the app or your Claude limits. Settings has Reset pairing to sign every other device out.
